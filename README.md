# Repositorio Técnico agentes-ia-pymes

## Descripción breve del objetivo
Este repositorio organiza un portfolio técnico en castellano para diseñar y documentar 10 agentes orientados a pequeñas y medianas empresas. El foco es construir una base demostrable de IA (*Artificial Intelligence – Inteligencia Artificial*) aplicada, automatización gradual y procesos operativos reales.

## Estado actual del repositorio
El repositorio está en fase inicial.

Estado a fecha de esta versión documental:
- Estructura base de carpetas y documentación creada.
- Inicio de desarrollo documental en `01-agente-onboarding-inteligente`.
- Agentes `02` a `10` reservados como línea futura, sin desarrollo funcional ni documental completo.

## Problema general que aborda
Muchas PYMES (*Small and Medium-sized Enterprises – Pequeñas y Medianas Empresas*) tienen procesos críticos dispersos, con baja estandarización y alta dependencia manual. Este portfolio aborda ese problema mediante diseños de agentes que ayuden a estructurar información, mejorar trazabilidad y preparar automatizaciones progresivas con enfoque implementable.

## Criterios técnicos del portfolio
- Trazabilidad: cada agente debe documentar objetivo, alcance y límites de forma verificable.
- Escalabilidad documental: estructura uniforme para facilitar mantenimiento y comparación.
- Separación de fases: distinción explícita entre V1 (*Version 1 – Versión 1*) implementable, V2 (*Version 2 – Versión 2*) futura y fuera de alcance.
- Realismo técnico: no declarar como implementado lo que todavía es diseño o planificación.
- Reutilización: uso de plantillas comunes para reducir ambigüedad documental.

## Estructura del repositorio
- `README.md`: presentación técnica general del portfolio.
- `CATALOGO.md`: inventario de agentes y estado general.
- `docs/`: visión global y criterios técnicos transversales.
- `plantillas/`: plantillas base para documentación de agentes.
- `agentes/`: carpetas individuales de cada agente.

Dentro de cada agente se mantiene una base común:
- `README.md`
- `docs/ARQUITECTURA.md`
- `docs/CASO_USO.md`
- `docs/ROADMAP.md`
- `requirements.txt`
- `.gitignore`
