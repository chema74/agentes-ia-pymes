# Repositorio Agentes IA PYMES

Este repositorio agrupa un portfolio técnico en castellano de agentes orientados a IA (Artificial Intelligence, Inteligencia Artificial) aplicada a PYMES (Small and Medium-sized Enterprises, Pequeñas y Medianas Empresas).

## Objetivo
Construir una base documental y técnica progresiva para 10 agentes demostrables, centrados en automatización de procesos reales, trazabilidad operativa y evolución futura hacia integraciones con Google Workspace.

## Alcance inicial
- V1 implementable: infraestructura documental, estructura de carpetas y definición de alcance técnico.
- V2 futura: integraciones con Google Workspace, paneles operativos, clasificación automatizada y soporte avanzado con IA.
- Fuera de alcance: desarrollo funcional completo, despliegue productivo y automatizaciones conectadas en esta fase.

## Estructura principal
- gentes/: agentes individuales del portfolio.
- docs/: visión y criterios de diseño del repositorio.
- plantillas/: plantillas para estandarizar la documentación de cada agente.
