# Agente Generador de Propuestas para PYMES

## Descripción breve

Este agente está pensado para ayudar a una pequeña o mediana empresa a estructurar propuestas comerciales, presupuestos iniciales o documentos base a partir de información mínima y criterios revisables.  
Su objetivo es ordenar datos dispersos y convertirlos en un borrador conceptual más claro, homogéneo y fácil de revisar por una persona responsable.  
El enfoque está orientado a PYMES (*Small and Medium-sized Enterprises – Pequeñas y Medianas Empresas*) que necesitan una base técnica demostrable sin montar una infraestructura compleja.  
En su estado actual, el agente es una base documental inicial, no un producto terminado ni una automatización funcional.

## Problema que aborda

En muchas PYMES, la preparación de propuestas se apoya en documentos antiguos, criterios informales o plantillas que se reutilizan sin suficiente revisión. Esto puede producir propuestas inconsistentes, alcances poco claros y documentos que no reflejan bien la necesidad real del cliente.

Los problemas habituales que aborda este agente son:

- Propuestas preparadas desde documentos antiguos.
- Presupuestos inconsistentes entre clientes.
- Alcances poco claros.
- Condiciones copiadas sin revisión.
- Falta de estructura común.
- Dependencia de una persona que sabe cómo se hacen.
- Riesgo de enviar documentos incompletos.
- Pérdida de tiempo preparando borradores desde cero.

El objetivo no es sustituir el criterio comercial, sino proporcionar una base más ordenada para revisar y preparar propuestas con coherencia interna.

## Usuario objetivo

Este agente está pensado para organizaciones pequeñas o equipos que preparan propuestas recurrentes y necesitan una forma más estructurada de trabajar.

Perfiles posibles:

- Consultorías pequeñas.
- Agencias de servicios.
- Despachos profesionales.
- Empresas de formación.
- Estudios creativos.
- Empresas de mantenimiento.
- Equipos comerciales pequeños.
- Profesionales que preparan propuestas recurrentes.

El diseño conceptual está orientado a empresas sin infraestructura técnica compleja, sin necesidad inicial de CRM completo, integraciones avanzadas o automatizaciones productivas.

## Objetivo funcional

El objetivo funcional es ayudar a convertir información comercial dispersa en una propuesta inicial más clara, revisable y homogénea. La propuesta se centra en documentar qué información mínima debe existir para que una persona pueda revisar el alcance, las condiciones y la estructura general antes de enviar cualquier documento.

La base funcional prevista incluye:

- Recogida de datos mínimos de la oportunidad.
- Definición del servicio propuesto.
- Delimitación preliminar de alcance.
- Estructura de entregables.
- Identificación de condiciones pendientes.
- Preparación de borrador conceptual.
- Revisión humana antes de enviar cualquier propuesta.

La revisión humana es un principio central del diseño: cualquier borrador, recomendación o estructura propuesta debe poder ser revisada por una persona antes de usarla con un cliente real.

## Alcance V1 implementable

La V1 (*Version 1 – Versión 1*) implementable debe ser pequeña, realista y verificable. Su objetivo es crear una base documental y técnica que permita demostrar el caso de uso sin presentar capacidades que todavía no existen.

El alcance previsto para esta V1 puede incluir:

- Documentación funcional y técnica.
- Definición del flujo de preparación de propuesta.
- Modelo conceptual de datos.
- Plantilla conceptual de propuesta.
- Ejemplo ficticio de propuesta.
- Reglas simples para detectar campos incompletos.
- Reglas simples para marcar condiciones pendientes.
- Preparación para automatización futura.

Esta V1 no implica todavía generación automática real, IA generativa funcional, exportación PDF ni integración con Google Workspace. Tampoco implica captura automática de requisitos, cálculo avanzado de precios ni envío automático a clientes.

## Evolución V2 futura

La V2 (*Version 2 – Versión 2*) futura describe una posible evolución del agente cuando la base documental esté validada y exista una primera implementación verificable. Esta sección no describe funcionalidades implementadas, sino opciones razonables para una fase posterior.

Una evolución futura podría incluir:

- Formulario de entrada de oportunidad.
- Registro en Google Sheets.
- Generación documental en Google Docs.
- Exportación futura a PDF (*Portable Document Format – Formato de Documento Portátil*).
- Plantillas reutilizables.
- Resumen asistido con IA.
- Sugerencias de estructura de propuesta.
- Dashboard de propuestas en curso.
- Integración futura con CRM.

También podría contemplarse el uso de una API (*Application Programming Interface – Interfaz de Programación de Aplicaciones*) si en el futuro existiera una necesidad real de conectar el agente con otros sistemas.

Esta sección describe posibilidades futuras, no funcionalidades implementadas.

## Fuera de alcance inicial

Quedan fuera del alcance inicial:

- Generación automática completa de propuestas.
- Envío automático a clientes.
- Firma digital.
- Cálculo financiero avanzado.
- Gestión contractual avanzada.
- Sustitución de criterio comercial.
- Integración real con CRM.
- Integración real con Google Workspace.
- Exportación PDF funcional.
- API pública.
- Multiempresa real.
- Métricas de conversión no verificadas.

El agente no debe presentarse como una solución cerrada de ventas ni como un motor autónomo de documentación comercial. En esta fase es un caso técnico documental preparado para revisión y posible evolución posterior.

## Entradas previstas

En una fase futura, el agente podría trabajar con entradas mínimas asociadas a la oportunidad comercial.

Entradas posibles:

- Nombre del cliente.
- Empresa.
- Tipo de oportunidad.
- Servicio propuesto.
- Necesidad principal.
- Alcance preliminar.
- Entregables previstos.
- Plazo estimado.
- Condiciones comerciales pendientes.
- Responsable interno.
- Observaciones internas.

Todavía no existe un sistema funcional de captura de estas entradas. No hay formularios implementados, integración con hojas de cálculo, conexión con documentos externos ni sincronización automática con herramientas externas.

## Salidas previstas

En una fase futura, el agente podría generar salidas orientadas a la revisión comercial y a la preparación de borradores.

Salidas posibles:

- Borrador estructurado de propuesta.

- Alcance preliminar revisable.
- Entregables propuestos.
- Condiciones pendientes.

- Recomendaciones para revisión humana.

Todavía no existe generación automática implementada. Cualquier salida descrita en esta sección corresponde a una capacidad prevista o diseñable, no a una funcionalidad actualmente disponible.

## Criterios de validación

Para validar la calidad documental y técnica del agente, pueden utilizarse las siguientes preguntas:

- ¿Se entiende qué problema resuelve?
- ¿La V1 puede implementarse sin sobreingeniería?
- ¿Está claro qué no está implementado?
- ¿La evolución futura está separada del alcance actual?
- ¿El agente puede demostrarse con datos ficticios de propuesta?
- ¿Existe revisión humana antes de enviar cualquier documento?
- ¿No se promete generación automática inexistente?

Si el documento permite responder afirmativamente a estas preguntas, la base del agente será suficientemente clara para avanzar hacia arquitectura, caso de uso y roadmap sin confundir alcance actual con evolución futura.
