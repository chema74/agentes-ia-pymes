# Plan de Formación Ficticio

## Propósito

Mostrar un ejemplo ficticio de plan de formación interna para comprobar si la información mínima de una PYME queda suficientemente ordenada.

## Estado actual

- Fase documental V1 (*Version 1 – Versión 1*): preparada.
- Plan funcional real: no implementado todavía.
- Automatización real: no implementada todavía.

## Advertencia sobre datos ficticios

Este plan no representa una plataforma funcional. Es un caso técnico ficticio, útil solo para documentación, validación manual y portfolio. No contiene promesas de mejora garantizada ni métricas de aprendizaje no verificadas.

## Contexto ficticio de empresa

La empresa ficticia es una PYME de servicios llamada NexoSur Formación Interna, S.L. Gestiona formación sobre procesos, herramientas, atención al cliente, documentación interna y buenas prácticas con equipos mixtos.

## Criterios formativos

- Cada ruta debe tener identificador, estado, prioridad y responsable.
- Cada ruta debe vincularse a un perfil interno.
- Cada módulo debe indicar tipo de contenido y estado.
- Si existe evidencia, debe ser visible y revisable.
- Las acciones siguientes deben indicar el próximo paso.

## Resultado esperado

El plan debe permitir detectar qué rutas avanzan, cuáles están bloqueadas y qué revisión humana falta para mantener control formativo sin automatización real.

## Limitaciones

- No existe LMS funcional.
- No existe automatización formativa real.
- No existe dashboard funcional.
- No existe Google Workspace.
- No existe CRM.
- No existe API.
- No existe IA funcional.

## Evolución posible V2

- Añadir filtros y vistas por área.
- Introducir métricas operativas.

## Criterios de validación

- Deben existir rutas en distintos estados.
- Deben existir módulos visibles y coherentes.
- Las evidencias deben estar ligadas a módulos concretos.
- Las acciones siguientes deben estar ligadas a rutas concretas.
- El plan debe coincidir con el modelo de datos y el caso de uso.

## Próximos pasos

- Usar este plan como referencia para la validación manual.
- Mantenerlo como ejemplo ficticio, no como plataforma de formación real.
