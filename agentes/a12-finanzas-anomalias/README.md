## ¿Qué Problema Resuelve?

Las PYMES pierden **~5% de ingresos anuales** por fraude financiero no detectado.  
Este agente identifica transacciones sospechosas **en segundos**, con **explicaciones claras** de por qué se activó la alerta, sin necesidad de GPUs costosas ni licencias caras.
