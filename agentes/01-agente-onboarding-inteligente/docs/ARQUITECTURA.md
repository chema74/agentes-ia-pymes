# Arquitectura Inicial

## Propósito
Establecer un diseño de referencia para ordenar el proceso de onboarding de clientes en PYMES, sin desarrollo funcional en esta fase.

## Flujo de referencia V1 implementable
1. Entrada estructurada de datos del cliente.
2. Validación inicial de completitud.
3. Aplicación de checklist operativo de onboarding.
4. Clasificación inicial por criterios predefinidos.
5. Preparación de expediente documental.

## Componentes conceptuales
- Módulo de captura de datos.
- Módulo de checklist operativo.
- Módulo de clasificación inicial.
- Módulo de consolidación de expediente.

## Evolución V2 futura
- Integración con Google Workspace para formularios, almacenamiento y seguimiento.
- Generación semiautomática de documentos de alta.
- Panel de control operativo con indicadores clave.
- Soporte de IA para clasificación asistida y recomendaciones.

## Fuera de alcance
- Implementación de conectores reales.
- Motor de IA en producción.
- Operación multiempresa con controles avanzados.
