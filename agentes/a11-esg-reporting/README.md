---

## 🎯 ¿Qué Problema Resuelve?

El 80% de las PYMES no tienen herramientas asequibles para generar informes de sostenibilidad (ESG) requeridos por la normativa CSRD. Este agente calcula métricas ambientales, sociales y de gobernanza a partir de datos básicos, generando informes auditables en segundos.
