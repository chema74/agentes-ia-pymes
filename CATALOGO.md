# Catálogo de Agentes IA para PYMES

## Objetivo del catálogo

Este catálogo resume los 10 agentes del repositorio como piezas de portfolio técnico. Cada agente valida una estructura local concreta sobre datos ficticios y deja evidencia reproducible para revisión humana.

## Estado general

- El repositorio contiene 10 agentes locales funcionales.
- Cada agente trabaja sobre datos ficticios en JSON (*JavaScript Object Notation - Notación de Objetos de JavaScript*).
- Cada agente tiene script local y pruebas `unittest`.
- La validación global se ejecuta con `python scripts/validar_repositorio.py`.
- No hay IA (*Artificial Intelligence - Inteligencia Artificial*) funcional, API (*Application Programming Interface - Interfaz de Programación de Aplicaciones*) productiva, dashboard productivo, Google Workspace ni integraciones reales.

## Agente 01 - Agente de Onboarding Inteligente

Valida localmente un expediente ficticio de onboarding y estructura un informe técnico de revisión humana.

## Agente 02 - Agente Documental Inteligente

Valida localmente un inventario documental ficticio y organiza incidencias de revisión documental sobre datos de ejemplo.

## Agente 03 - Agente de Seguimiento de Clientes

Valida localmente una cartera ficticia de clientes y ordena el seguimiento operativo sin usar un CRM (*Customer Relationship Management - Gestión de Relaciones con Clientes*) real.

## Agente 04 - Agente Generador de Propuestas

Valida localmente una propuesta ficticia y estructura la información mínima de revisión sin generar propuestas reales.

## Agente 05 - Agente de Operaciones para PYMES

Valida localmente tareas y bloqueos operativos ficticios para mostrar control básico de operaciones con datos de ejemplo.

## Agente 06 - Agente de Control de Cobros y Flujo de Caja

Valida localmente cobros y previsiones operativas ficticias para revisar tensión de caja sin sustituir asesoría financiera.

## Agente 07 - Agente de Pipeline Comercial

Valida localmente oportunidades comerciales ficticias y ordena el estado del pipeline sin conectar con procesos comerciales reales.

## Agente 08 - Agente de Formación Interna

Valida localmente rutas, módulos y evidencias formativas ficticias, como estructura base de seguimiento tipo LMS (*Learning Management System - Sistema de Gestión del Aprendizaje*).

## Agente 09 - Agente de Análisis de Mercado

Valida localmente señales de mercado ficticias y organiza observaciones operativas sin hacer analítica predictiva ni consulta externa.

## Agente 10 - Agente de Revisión y Cumplimiento

Valida localmente controles, evidencias y hallazgos ficticios para representar una revisión interna con límites claros de alcance.

## Criterio de lectura del catálogo

- V1 implementada: validación local, datos ficticios, revisión humana y pruebas reproducibles.
- V2 futura: automatizaciones, integraciones o capas funcionales posteriores.
- Fuera de alcance actual: producto terminado, decisiones automáticas, integraciones vivas o promesas no implementadas.
